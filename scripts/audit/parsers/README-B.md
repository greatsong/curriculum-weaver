# parsers — 담당 B (별책7 사회 · 별책8 수학 · 별책9 과학)

## 파일
- `common_b.py` — 공통 로직(pdftotext 실행, 줄 단위 상태기계, HWP 병합, 스키마 출력, CLI). `extract_volume(volume, pdf, hwp=None)`.
- `hwp_b.py` — HWP5 레코드 직접 파싱(표 셀 문단 포함, 수식 EQEDIT 스크립트 인라인 `⟪script⟫`) + 수식 스크립트 → 1줄 표기 렌더러.
- `book7.py`, `book8.py`, `book9.py` — 얇은 래퍼. `python3 book8.py --pdf <PDF> [--hwp <HWP>] --out <JSON>` (exit 0/1), `extract(pdf_path, hwp_path=None) -> dict`.

## 의존
- 시스템: `pdftotext` (poppler). `-enc UTF-8`, 비-layout 모드로 임시 디렉터리에 추출(`tempfile`).
- 파이썬: 표준 라이브러리 + `olefile` (HWP 컨테이너 읽기). pyhwp(`hwp5txt`)는 표를 `<표>`로 치환하고 수식을 버리므로 사용하지 않는다.
- 결정적: 입력 파일만으로 출력이 정해진다(시간·경로·난수 무관). `source_file`은 입력 PDF의 basename.

## 레이아웃 규칙(세 별책 공통, Hancom PDF·Distiller PDF 모두)
- 머리글(`○○과 교육과정`, `공통 교육과정`, `선택 중심 교육과정 – 일반 선택 과목 -`; 별책7은 끝의 `-`가 다음 줄로 밀림)·쪽번호(숫자만인 줄)는 제거.
- 과목 제목 = `1. 성격 및 목표`/`교육과정 설계의 개요` 직전의 짧은 평문 줄. 구분(공통/일반선택/진로선택/융합선택)은 차례(`[일반 선택 과목]` 아래 항목)에서 결정.
- `나. 성취기준` ~ `3. 교수⋅학습 및 평가`(또는 `가. 내용 체계`) 사이만 파싱. `[초등학교 3~4학년]`류 학년군 표지, `[한국사 1]`·`<통합과학2>`·`[공통수학1]`류 과목 표지(차례 과목명과 대조), `<지리 영역>`류 그룹 표지에서 영역 번호를 (1)로 재시작.
- 영역 소제목 `(n) …`은 번호가 직전+1일 때만 인정(고려사항 불릿 안의 `(1)` 나열 오인 방지).
- 코드 행 `[코드] 본문`: 다음 구조 행까지의 줄을 연속행으로 결합. 별책8은 표 왼쪽 열(주제 라벨)이 코드 행 뒤에 끼어들므로 문장 종결(`다.`) 이후의 줄은 버림. 별책9의 `<탐구 활동>` 블록은 다음 구조 행까지 건너뜀. 별책7은 불릿 첫 줄 뒤에 빈 줄이 끼므로 빈 줄을 구분자로 쓰지 않는다.
- `(가) 성취기준 해설` 불릿: 선두 `[코드]`(병기 `[A], [B]`, 범위 `[A]~[B]`, 괄호 안 범위 `[9과06-02∼03]`, 나열 `[12전자01-01,03]`)를 각 코드로 확장·복제하고, 코드 표기 오타(`[9사(일사]11-01]`, `[12동역-01-01]`, `[10과탐02-01-03]`, `[9사(일사)08-2]`)는 영역 코드 목록과 느슨 비교로 보정(모두 notes 기록). 본문은 코드 표기와 직결 조사(은/는/이/가…)를 뗀 텍스트. 코드 없는 불릿은 `area_explanation`(추가 필드)에 보존.
- `(나) 성취기준 적용 시 고려 사항`: 불릿을 `\n`으로 연결(불릿 글리프 제거). `없음`은 빈 값.
- 학년군/학교급은 코드 접두(2/4/6/9/10/12)로 결정.

## 줄바꿈 접합의 띄어쓰기
- HWP가 있으면(별책7·8) 접합 지점의 앞 토큰+뒤 토큰이 HWP 문단에 붙어 있는지/띄어 있는지로 판정. 그 외 문자(공백 아님)가 다르면 PDF를 유지하고 notes에 기록.
- HWP가 없으면(별책9) 문서 내 행 내부 토큰 코퍼스에 `앞+뒤`가 존재할 때만 붙임(그 외 띄움). `⋅`·여는 괄호 뒤, 닫는 괄호·문장부호 앞은 항상 붙임. 검증기는 공백을 무시하므로 일치율에는 영향 없음.

## 수식 복원(별책8)
- PDF는 수식을 HyhwpEQ 폰트의 사설영역 글리프(U+E000~)로 내보내고 분수·근호는 줄이 갈라진다. `hwp_b.hwp_paragraphs()`가 HWP 본문 레코드(PARA_TEXT의 확장 컨트롤 문자 ↔ CTRL_HEADER `eqed` ↔ EQEDIT 스크립트)를 순서대로 맞춰 문단 안 제자리에 `⟪script⟫`로 넣는다.
- 병합 시 PDF 단위에 사설영역 문자가 있거나 대응 HWP 문단에 수식이 있으면 HWP 문단을 렌더링해 채우고, 원 스크립트를 notes에 `[코드] content 수식 복원(HWP 스크립트): …`로 남긴다.
- 렌더링 규칙: `{a} over {b}`→`a/b`(복합식은 괄호), `sqrt{x}`→`√(x)`, `^{n}`/`_{k}`→유니코드 첨자(없으면 `^(…)`), `TIMES`→`×`, `sum _{k=1}^{n} k`→`∑ₖ₌₁ⁿ k`, `LEFT { … RIGHT }`→`{ … }`, 함수명 뒤 공백(`ln x`), 폰트 명령(`rm`/`it`)과 간격 기호(`` ` ``, `~`) 제거. 의미를 바꾸는 축약은 하지 않는다.
- 두 원문 모두 사설 글리프로만 있는 기호(중학교 도형 기호 목록의 닮음 기호로 추정되는 HWP U+F0040, 별책7 『 』로 추정되는 U+F0000대 문자)는 원문 그대로 두고 notes에 기록.
