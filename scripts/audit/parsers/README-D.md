# 담당 D 파서 — 별책16·19·20·21·22

## 사용
```
python3 parsers/book20.py --pdf "<PDF>" [--hwp <HWP>] --out <JSON> [--diag <log>]   # exit 0/1
python3 -c "import parsers.book20 as b; d = b.extract('<PDF>')"                      # extract(pdf_path, hwp_path=None) -> dict
```
공통 로직은 `common_d.py` (다른 담당의 common_c/common_e와 독립). 절대경로 하드코딩 없음, 임시파일 사용 안 함(메모리 처리), 결정적.
`--hwp`는 인터페이스 호환용이며 이 5권은 HWP를 쓰지 않는다(주어지면 notes에 기록만).

## 의존
`pymupdf`(fitz) 만 필수. python3.9+.

## 레이아웃 규칙 (common_d.py 상단 상수)
- 러닝 헤드 y0<65: 짝/홀 페이지에 "책 제목" 또는 "구분 - 과목명"(예: `진로 선택 과목 - 고급 대수`, `공통 교육과정 - 생활 독일어`). 과목명·curriculum_category는 그 과목의 성취기준 구간 페이지들에서 가장 많이 나온 헤드로 결정.
- 꼬리글(쪽번호): 754pt 판형 y0>690, A4(별책19, 841pt) y0>740.
- 같은 페이지·같은 기준선(y 겹침)의 조각 라인은 x 순으로 병합(수식 span 분리 대응). 줄 결합은 "앞줄 끝공백이 있으면 공백, 없으면 붙임"(HWP 글자 단위 줄바꿈), 라틴/숫자 시작 줄은 공백.
- 구간: `나. 성취기준` ~ `3. 교수` . 영역 소제목 `(n) …`(x0<89), 코드 행 `[코드] …`(x0<95, 여는 대괄호 누락도 허용→code_as_printed), `(가) [영역] 성취기준 해설`, `(나) [영역] 성취기준 적용 시 고려 사항`(별책21은 "영역" 삽입, 별책19는 "고려사항" 붙여씀), 불릿 `•`. `<표`/`[그림` 캡션 이후는 다음 소제목까지 무시(별책21 신체활동 예시 표).
- 해설 매핑: 선두 `[코드]` 묶음(`, `·`와/과` 연결, 범위 `01∼02`, 병기 `05-01/02/04` 전개). 코드 오식은 같은 영역 내 접미 번호 유일 매칭(`[12러회01-9]`, `[12삶종교01-03]`, `[논술01-02]`). `없음`/`<없음>`은 해설 없음. 코드 없는 불릿은 notes에 전문 보존.
- 학교급/학년군은 코드 접두 숫자(9→중학교/중1-3, 12→고등학교/고선택). 소제목 없는 과목(별책16 회화·문화 16종)은 area "" 단일 영역.
- 원문 오식 보정(모두 notes + code_as_printed 보존): 별책21 `[12스경02-02]` 중복 인쇄 → 두 번째를 02-03, 별책22 `12연몸02-04]` 대괄호 누락.
- 글리프 복원(PDF 렌더링 육안 확인, 책별 표, 모두 `\uXXXX` 이스케이프): 별책20 `PUA_FIX`(content/explanation 12곳) + `NOTES_FIX`(적용 고려사항 '용어와 기호' 불릿 9영역 11치환, 키=글리프 시퀀스 원문, 주석에 page/bbox). 표기 규칙: 유니코드 수학기호·첨자 우선(⁻¹ ² ⁿ ₙ ᵣ ᵀ σ ∫ ∞), 없으면 ASCII(∫_a^∞, x^n), 분수 a/b, 벡터 →AB. 별책16 `JP_FIX` 일본어 CID 폰트 깨짐 24문자열. 산출 5권 모두 사설영역 문자 0.
