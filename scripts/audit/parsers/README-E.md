# 별책23 파서 (E 담당) — `book23.py` + `common_e.py`

## 사용
```bash
python3 official/parsers/book23.py --pdf "<…/[별책23] 경영·금융 전문 교과 교육과정.pdf>" [--hwp <HWP>] --out official/별책23.json
python3 official/validate_official.py official/별책23.json      # RESULT PASS 확인
```
- 파이썬 API: `from book23 import extract; extract(pdf_path, hwp_path=None) -> dict` (SPEC.md 구조)
- exit 0 = 성공, 1 = 실패(메시지 stderr). 절대경로 하드코딩 없음, 임시 파일 사용 안 함(전부 메모리 처리). 결정적(2회 실행 바이트 동일).
- `--hwp`는 인터페이스 호환용. 별책23은 수식·PUA 글리프가 없어 사용하지 않는다.
- 의존: `pymupdf`(fitz) 1.2x, Python 3.9+ (표준 라이브러리 외 다른 의존 없음). pdftotext는 필요 없음.

## 레이아웃 규칙 (2022 개정 별책23 PDF, A4 595×841pt, 618쪽)
| 요소 | 판별 기준 |
|---|---|
| 페이지 헤더 / 쪽번호 | y0 < 60 / y0 > 770 → 본문에서 제외. 헤더 `전공 실무 과목 - N. 과목명`(하이픈 또는 en-dash)에서 **구분(전문공통·전공일반·전공실무)** 추출 |
| 과목 경계 | 글자 크기 ≥ 20pt(실제 21pt) 표제 `N. 과목명`. 표제 번호가 1로 되돌아가면 다음 구분(헤더 값이 우선). 20pt 이상이면서 표제 형식이 아닌 줄(`과목명 축약 글자` 부록 제목)은 과목 구간 종료 |
| 성취기준 절 | `나. 성취기준`(≥11.5pt)부터 `3. 교수·학습`/`4. 평가`(≥13pt)까지 |
| 학습 영역 / 요소 | `1) …`(x0<92) = 영역, `가) …`(92≤x0<110) = 요소. **area = `1) 영역 > 가) 요소`**, 요소 소제목이 없는 과목(성직·인산·디직 등)은 `1) 영역`만 |
| 성취기준 | 줄 머리 `[약어 NN-NN(-NN)]`(x0≈89, 9.9pt). 이어지는 줄은 x0≈148 |
| 적용 고려사항 | `<성취기준 적용 시 고려 사항>` 뒤의 `• …` 불릿(x0≈86, 이어지는 줄 x0≈98). `가)` 소제목과 불릿 이어짐 줄이 같은 x0라 **직전 줄 간격(>26pt) 또는 다음 줄이 코드인지**로 소제목을 판별 |
| 줄 결합 | fitz 줄 텍스트의 **끝 공백 글리프**를 그대로 살림: 있으면 띄어쓰기, 없으면 붙여쓰기(어절 중간 줄바꿈). 연속 공백은 1개로 축약 |

## 출력 필드 의미
- `content`: 성취기준 문장 verbatim.
- `explanation`: 이 별책에는 "(가) 성취기준 해설" 절이 **없다**. 대신 `• [코드] …` 형태의 적용 고려사항 불릿이 코드별로 붙으므로, 코드가 명시된 불릿 본문(코드 접두 제거)을 넣었다(정본 standards.json의 explanation과 같은 의미). 코드 뒤에 조사가 바로 붙은 불릿(`[A], [B]는 …`)은 코드 접두를 포함한 전문. 불릿 2개가 같은 코드를 인용하면 `\n`으로 이어 붙임. 원문에 불릿이 없는 코드(85개)는 빈 문자열.
- `application_notes`: 영역(학습 요소) 단위 불릿 전체를 불릿 기호만 떼고 `\n`으로 결합(코드 접두 유지). 코드 없는 불릿·다른 영역 코드를 인용한 불릿도 여기에는 모두 들어간다.
- `_orig_code`: 오기 정정표(`CODE_CORRECTIONS`)로 코드를 고친 항목에만 존재, 원문 표기 보존.
- `notes`: 고정 안내 8건 + 파싱 중 판단 기록(정정표 적용, 약어 매핑, 병기 코드, 미해결 인용 등).

## 원문 오기 처리 (book23.py 상단 dict, 근거는 주석)
- `CODE_CORRECTIONS`: `[노무 02-01-04]→[노관 02-01-04]`, 두 번째 `[원지 02-04-02]→[원지 02-04-03]`.
- `CITE_CORRECTIONS`: 불릿 인용 약어 오기 `[유통 05-01-0x]→[유관 …]` 4건.
- 표에 없는 중복 코드·이질 약어·미해결 인용은 정정하지 않고 notes에만 기록한다(새 PDF 판본에서 새 오기가 생기면 notes를 보고 표에 추가).
