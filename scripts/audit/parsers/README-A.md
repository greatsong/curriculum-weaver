# 담당 A 파서 — 별책2(초등학교)·별책5(국어과)·별책6(도덕과)

## 실행
```
python3 parsers/book2.py --pdf "<별책2 PDF>" --out 별책2.json          # exit 0/1
python3 parsers/book5.py --pdf "<별책5 PDF>" --out 별책5.json
python3 parsers/book6.py --pdf "<별책6 PDF>" [--hwp <HWP>] --out 별책6.json
python3 validate_official.py 별책N.json
```
파이썬 API: `from parsers import book2; book2.extract(pdf_path, hwp_path=None) -> dict` (스펙 스키마).
공통 로직은 `parsers/common_a.py`(다른 담당의 common_c/common_e와 무관). 절대경로 하드코딩 없음, 결정적(같은 입력→바이트 동일 출력, 3권 재실행으로 확인).
`--hwp`는 선택이며 hwp5txt가 있으면 사설영역 글자를 HWP 본문에서 찾아 복원을 시도한다(별책2·5·6은 대응 HWP가 없거나 수식이 텍스트가 아니라 실제 복원은 렌더링 확인 표로 처리).

## 의존 패키지
- Python 3.9+, `pymupdf`(fitz) — 유일한 필수 의존성
- 선택: `pyhwp`(hwp5txt) — `--hwp` 지정 시에만 사용

## 레이아웃 규칙 (교육부 별책 조판 공통)
| 요소 | 판정 규칙 |
|---|---|
| 머리글 / 쪽번호 | y < 62pt / y > 685pt 줄을 본문에서 제외. 머리글 문구로 교육과정 구분(공통·일반선택·진로선택·융합선택)을 읽음 |
| 줄 조립 | fitz `rawdict` 글자 좌표로 기준선 군집(허용 7pt) 후 x 정렬. 공백·사설영역 글자(수식 조각)는 가장 가까운 줄에 붙임(12pt). 줄 끝 공백 글리프가 보존되므로 이어붙일 때 "공백 있으면 띄우고, 없으면 붙임" |
| 과목명 | 별책2: 홀수 쪽 머리글(바른 생활·국어·사회 …). 별책5·6: `교육과정 설계의 개요` 또는 `1. 성격 및 목표` 바로 앞 줄. 큰 글꼴 대괄호 단독 줄(`[공통국어2]`)은 하위 과목 표제 → 과목 항목 분리 |
| 절 범위 | `나. 성취기준` ~ `3. 교수…`(또는 큰 글꼴 `n.`/`가.` 절 표제) |
| 학년군 표제 | `[초등학교 1∼2학년]` 등. 실제 grade_group은 코드 접두(2/4/6/9/10/12)로 결정 |
| 영역 소제목 | `(n) …` 이고 (글꼴 ≥ 11.2pt 또는 x0 < 88pt). 선택 과목처럼 소제목이 없으면 area="" |
| 코드 줄 | `[코드] 본문`. 코드 안 en-dash·공백은 정규화(원문 표기는 notes에 기록). `[4과09-01∼02]` 범위 표기는 각 코드로 펼침 |
| 해설 (가) | 불릿(•, Ÿ, Wingdings PUA 등) 단위. 맨 앞 코드 라벨(쉼표·"와/과 [코드]" 연결 포함)을 떼고 본문만 explanation에. 여러 코드 병기 시 모두에 넣고 notes 기록 |
| 고려 사항 (나) | 불릿 본문을 `\n`으로 연결해 영역의 application_notes. 학년군이 섞인 영역(초등 도덕)은 각 학년군 항목에 동일 수록 |
| 제외 대상 | 과학 `<탐구 활동>` 블록, 수학 영역 안 소제목 줄(U+F000 글리프+짧은 제목), 절 안의 표(`<표 n>` 이하 9.5pt 미만 행 — 체육) |
| 사설영역 글리프 | 렌더링으로 확인한 표: e048=+, e046=−, e047==, {e034,e06d,e035}=1/2, F000=『 』(여닫이 교대). 남으면 원문대로 두고 notes 기록 |
