## 공통 레이아웃 규칙 (6권 동일 조판)
- 텍스트는 `page.get_text('rawdict')`의 문자를 이어 붙여 **줄 끝 공백 글리프를 보존** → 줄바꿈 접합 시 "공백 있으면 띄어 붙임, 없으면 붙여 씀". (pdftotext는 줄 끝 공백을 버려 띄어쓰기를 결정할 수 없음)
- 페이지 정렬: y 3pt 버킷 → x0. 같은 y의 조각 줄은 x 순으로 병합(간격 2pt 초과면 공백 삽입).
- **머리글 제거**: `y0 < 60`(9pt 러닝 헤드 "○○과 교육과정" / "공통 교육과정 - ○○" / "선택 중심 교육과정 – 일반 선택 과목 -"). **쪽번호**: `y0 > 690`이고 숫자만.
- **과목 경계**: 26pt 이상 구분 페이지("공통 교육과정", "- 일반/진로/융합 선택 과목 -", 영어의 "- 공통 과목 -") → `curriculum_category`; 21pt 표제(페이지 상단 y<130) → `subject`. 학년군·학교급은 코드 접두(4/6/9/10/12)로 결정하므로 표제 하나에 여러 학년군이 있으면 subject를 학년군별로 분리(실과(기술⋅가정)=초5-6+중1-3, 영어=초3-4/초5-6/중1-3, 체육·음악·미술 동일).
- **성취기준 섹션**: `나. 성취기준` ~ `3. 교수⋅학습 및 평가`(또는 13pt+ 번호 제목). `가. 내용 체계`가 나오면 섹션 종료(하위 과목 반복 대비). `[초등학교 3∼4학년]` 같은 학년군 머리글은 스킵.
- **영역**: x0<85 (또는 x0<100이고 다음 줄이 코드)인 `(n) 이름`. 코드가 영역 머리글 없이 바로 나오면 `area: ""`.
- **코드 줄**: x0<90에서 `[코드]`로 시작. 이어지는 줄(x0≥90)은 content에 접합.
- **(가) 성취기준 해설 / (나) 적용 시 고려 사항**: `•`(또는 Wingdings U+F09F/U+F06C/U+F0A7) 글머리 x0<95를 불릿 시작으로, x0≈103 줄은 접합, 92<x0<101이고 기호로 시작하는 줄(―, ①, ⋅)은 하위 항목으로 `\n` 구분. 고려사항 불릿은 `\n`으로 이어 붙여 `application_notes`. 표(8.8pt)는 넣지 않고 notes에 "표 생략"으로만 남김.
- **해설 병기 처리**: `[A], [B]` / `[A]~[B]`(같은 영역이면 번호 범위 확장) / 축약형 `[9체02-01, 04, 07]` → 모든 코드에 동일 해설 배정 + notes 기록. 한 코드에 해설 불릿이 둘이면 `\n`으로 이어 붙임. 코드 목록에 없는 코드를 가리키는 불릿은 `area.unassigned_explanations[{label,text}]`로 보존.
- **조사 제거**: 체육처럼 `[코드]은/는 …`(조사가 `]`에 바로 붙음)일 때만 조사를 떼고 본문을 explanation에 넣음. `[코드] 이 성취기준은 …`은 그대로.
- 부록/별표(`[부록]`, `[별표]`로 시작하는 제목) 이후는 무시. NFC 정규화, PUA 잔존 검사(현재 0).
