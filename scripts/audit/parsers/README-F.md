# parsers/book18.py — 별책18 중학교 선택 교과(환경·보건·진로와 직업)

## 실행
```
python3 parsers/book18.py --pdf "[별책18] 중학교 선택 교과 교육과정.pdf" \
    --hwp "[별책18] 중학교 선택 교과 교육과정.hwp" --out out/별책18.json   # exit 0/1
python3 -c "import book18; d = book18.extract(pdf, hwp)"                   # API
```
exit 1 = 도구 부재/변환 실패, 코드 0건, 또는 HWP↔PDF 교차검증 불일치 발생.

## 의존
- `pdftotext` (poppler) — PATH 또는 env `PDFTOTEXT`
- `hwp5html` (pyhwp; `pip install pyhwp`) — PATH 또는 env `HWP5HTML`, 없으면 `python -m hwp5.hwp5html`. `--hwp` 생략 시 불필요
- python3 표준 라이브러리만 사용. 임시 파일은 `tempfile.TemporaryDirectory`(hwp5html 출력) 뿐, 절대경로 하드코딩 없음

## 소스 선택 이유
- 성취기준 본문은 HWP **표 안**에 있어 `hwp5txt`는 `<표>`로 생략한다. `hwp5html`의 xhtml은 표 셀 문단까지 문서 순서로 내준다.
- PDF 텍스트는 줄 끝 띄어쓰기를 복원할 수 없다(Hancom PDF는 어절 중간 줄바꿈 `탐구|한다`에도 줄 끝 공백 글리프를 넣음). 그래서 HWP가 1차 소스, PDF는 공백 제거 비교로 교차검증만 한다. HWP 없이 돌리면 PDF 문단을 공백으로 이어 붙이고 notes에 불확실 경고를 남긴다.

## 레이아웃 규칙(별책18)
- 과목 블록: `나. 성취기준` ~ `3. 교수⋅학습 및 평가`. 과목명은 코드 접두(9환→환경, 9보→보건, 9진로→진로와 직업)로 결정. school_level 중학교, grade_group 중1-3, curriculum_category는 쪽머리글 "공통 교육과정 - 환경" 표기를 따라 `공통`.
- 영역: `(N) 영역명` 문단. 이어서 코드 표(`[9환01-01] …` 문단 하나가 성취기준 하나), `(가) 성취기준 해설`, `(나) 성취기준 적용 시 고려 사항`(진로는 "고려사항"으로 붙여 씀 → 공백 허용 정규식).
- 해설 불릿 앞머리 코드 매핑: 첫 코드는 무조건, 둘째 이후 코드는 `] ` 또는 `],` 구분자가 있을 때만 병기로 간주(`[9보02-01] [9보01-04]에서 학습한…`의 둘째 코드는 본문 참조). 병기(`[9보03-01], [9보03-02] …`)는 두 코드 모두에 같은 해설을 넣고 notes 기록.
- 원문 오탈자 `[[9환01-01]`(이중 괄호)는 `[9환01-01]`로 매핑하고 notes 기록.
- PDF 문단 재구성: 쪽번호(`^\d{1,3}$`)·`중학교 선택 교과 교육과정`·`공통 교육과정 - 과목` 머리글 제거. 새 문단 = `(N) `, `•`, `(가)`, `(나)`, `나. 성취기준`, `3. 교수`; 코드 줄 `[9…`는 **성취기준 표 구간(영역 머리글 뒤~(가) 전)** 에서만 문단 시작(해설 본문 속 `[9환04-04] 성취기준과 같이…`가 줄머리에 오는 경우 오분리 방지).
- 공백 처리: 문단 안 연속 공백은 하나로, 앞뒤 공백 제거. 그 외 글자는 원문 그대로(마침표 보정 없음).
