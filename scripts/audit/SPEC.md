# 원문 구조화 추출 스펙 (교육부 고시 2022 개정 교육과정 별책 → JSON)

목적: 성취기준 정본(server/data/standards.js, 5,907건)의 **모든 필드**를 원문과 대조해 결점 0을 만들기 위한
"원문 구조화 데이터"를 별책별로 만든다. 원문에 없는 내용을 절대 지어내지 않는다(verbatim).

## 입력
- PDF: `/Users/greatsong/Downloads/260720/` 의 `[별책N] …pdf` (같은 번호가 여럿이면 크기가 가장 큰 파일 사용)
- 보조: `[별책8] 수학과 교육과정(2022 개정).hwp`, `[별책7] 사회과 교육과정.hwp` (수식·기호 복원용, `hwp5txt` 사용 가능)
- 정본 덤프(대조용): `SCRATCH/standards.json` — [{code, subject_group, subject, school_level, grade_group, content, explanation}]
- 도구: `pdftotext -enc UTF-8 [-layout]`, python `fitz`(PyMuPDF), `pdfplumber`, `hwp5txt`. 파이썬은 python3.

## 출력 (별책당 1파일) `SCRATCH/official/<별책N>.json`
```json
{
  "byeolchaek": "별책9",
  "source_file": "[별책9] 과학과 교육과정.pdf",
  "subjects": [
    {
      "subject": "과학",                       // 원문 과목명 그대로 (예: "통합과학1", "생활 독일어", "매장 판매")
      "school_level": "중학교",                 // 초등학교|중학교|고등학교|"" (전문교과는 "고등학교")
      "grade_group": "중1-3",                   // 초1-2|초3-4|초5-6|중1-3|고공통|고선택|기타 — 코드 접두로 결정: 2→초1-2, 4→초3-4, 6→초5-6, 9→중1-3, 10→고공통, 12→고선택, 한글약어→기타
      "curriculum_category": "공통",            // 원문에 표기된 구분: 공통|일반선택|진로선택|융합선택|전문공통|전공일반|전공실무|"" (없으면 "")
      "areas": [
        {
          "area": "(1) 과학의 기초",             // 성취기준 소제목의 영역명 원문 그대로 (번호 포함 가능)
          "codes": [
            { "code": "[9과01-01]", "content": "…다.", "explanation": "…" }   // explanation: "(가) 성취기준 해설"에서 이 코드에 붙은 해설. 없으면 "".
          ],
          "application_notes": "…"                // "(나) 성취기준 적용 시 고려 사항"의 불릿 전체를 줄바꿈("\n")으로 이어 붙인 원문. 없으면 "".
        }
      ]
    }
  ],
  "notes": ["추출 중 확신이 없는 지점 메모 …"]
}
```

## 규칙
1. **verbatim**: content·explanation·application_notes는 원문 글자 그대로. 줄바꿈으로 끊긴 단어는 붙인다(예: "설명할 수\n있다" → "설명할 수 있다"). 하이픈·기호는 원문 유지. 문장 끝 마침표가 원문에 없으면 붙이지 않는다.
2. **코드 형식**: `[6과03-01]`, `[10공영1-01-01]`, `[9사(지리)01-03]`, `[12미적Ⅰ-02-03]`, `[공관 01-01-01]`, `[성직 01-02]` 등 원문 표기 그대로(공백 포함 여부도 그대로).
3. **해설 매핑**: "(가) 성취기준 해설" 불릿은 보통 `[코드] 본문…` 형태. 한 불릿이 여러 코드를 병기하면(`[A], [B] 이 성취기준은…`) 그 해설을 **각 코드 모두**에 넣고 `notes`에 기록. 해설이 "없음"이면 "".
4. **수식/PUA**: PDF 텍스트에서 수식 글리프가 빠지거나 사설영역 문자(U+E000–F8FF)로 나오면 HWP(`hwp5txt`)로 같은 문장을 찾아 복원한다. 복원 불가 시 원문 그대로 두고 `notes`에 코드와 함께 기록.
5. **자기 검증(필수)**: 아래 검증기를 돌려 정본에 이미 있는 코드의 content 일치율이 99.5% 이상이어야 한다. 미달이면 추출 로직을 고쳐 재시도(최대 3회). 불일치 목록은 `notes`가 아니라 검증기 출력으로 남긴다.
   `python3 SCRATCH/official/validate_official.py SCRATCH/official/<별책N>.json`
6. **금지**: 정본을 참고해 원문을 "보정"하지 않는다. 정본은 검증에만 쓴다. 리포 파일을 수정하지 않는다. 출력은 SCRATCH 아래에만 쓴다.
7. 표 레이아웃(성취기준이 표 안에 있는 별책2·초등)은 `fitz`의 블록/워드 좌표로 셀 단위 재구성이 필요할 수 있다. `pdftotext -layout`도 시도한다.
