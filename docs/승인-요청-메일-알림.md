# 가입 승인 요청 메일 알림 설정

승인 대기 교사가 커리큘럼 위버에 들어오면 관리자 메일(greatsong21@gmail.com)로 알림 한 통을 보냅니다. 같은 교사로는 한 번만 보냅니다. 아래 설정을 하지 않으면 메일은 나가지 않고, 다른 기능에는 영향이 없습니다.

발송은 관리자의 구글 계정에서 실행하는 Apps Script가 맡습니다. 서버에는 메일 계정의 비밀번호를 두지 않습니다.

## 1. 발송 스크립트 만들기

1. 받는 주소의 구글 계정으로 https://script.google.com 에 들어가 새 프로젝트를 만듭니다.
2. 편집기의 내용을 지우고 `scripts/apps-script/approval-mail.gs`의 내용을 붙여 넣습니다.
3. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성 → 속성 추가에서 이름 `SECRET`, 값에 임의의 긴 문자열을 넣고 저장합니다. 이 값은 3단계에서 다시 사용합니다.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 배포 → 새 배포 → 유형 선택에서 웹 앱을 고릅니다.
2. 실행 계정은 "나", 액세스 권한은 "모든 사용자"로 정하고 배포합니다.
3. 권한 승인 화면에서 메일 발송 권한을 허용합니다.
4. 표시된 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다.

액세스 권한을 "모든 사용자"로 두어도 `SECRET`이 맞지 않는 요청은 메일을 보내지 않습니다. 받는 주소는 스크립트 안에 고정되어 있습니다.

## 3. 서버 환경 변수 넣기

Railway의 curriculum-weaver-server 서비스 Variables에 두 값을 추가합니다.

| 이름 | 값 |
|---|---|
| `APPROVAL_NOTIFY_WEBHOOK_URL` | 2단계에서 복사한 웹 앱 주소 |
| `APPROVAL_NOTIFY_SECRET` | 1단계에서 정한 `SECRET` 값 |

저장하면 서버가 다시 시작되고 알림이 켜집니다.

## 동작

- 보내는 시점: 승인 대기 교사가 로그인해 서버에 첫 요청을 보낼 때입니다.
- 메일 내용: 이름, 이메일, 가입 시각(한국 시간), 승인 화면 주소입니다.
- 중복 방지: 보낸 뒤 그 계정에 발송 시각(`approval_notified_at`)을 남깁니다.
- 실패 시: 서버 로그에 경고만 남기고, 그 교사의 다음 요청에서 다시 시도합니다.
- 설정 전부터 대기 중이던 교사는 다시 들어올 때 알림이 한 번 나갑니다.

## 끄기

Railway에서 두 환경 변수 중 하나를 지우면 메일이 나가지 않습니다.
