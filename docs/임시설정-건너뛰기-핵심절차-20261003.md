# 임시 설정: 건너뛸 수 없는 핵심 절차 변경 (2026-10-03)

교사 연수 동안만 쓰는 설정이다. 연수가 끝나면 아래 4절의 절차대로 되돌린다.

## 1. 무엇을 바꿨나

| 구분 | 원래 설정 | 연수 동안 |
|------|-----------|-----------|
| 건너뛸 수 없는 절차 | T-1 공동 비전 설정, **T-3 역할 배분**, A-2 비전에 적합한 주제 선정, A-3 주제의 상세 내용 분석, A-4 핵심 아이디어 도출 및 통합 수업목표 진술 | T-1 공동 비전 설정, **T-2 수업설계 방향 설정**, A-2, A-3, A-4 (같음) |
| T-2 수업설계 방향 설정 | 건너뛸 수 있음 | 건너뛸 수 없음 |
| T-3 역할 배분 | 건너뛸 수 없음 | 건너뛸 수 있음 (호스트·소유자) |

- 상수: `shared/constants.js`의 `UNSKIPPABLE_PROCEDURES`
  - 원래 값: `['T-1-1', 'T-2-1', 'A-1-2', 'A-2-1', 'A-2-2']`
  - 연수 값: `['T-1-1', 'T-1-2', 'A-1-2', 'A-2-1', 'A-2-2']`
- 준비(prep)는 별도 규칙(`isProcedureSkippable`)으로 계속 건너뛸 수 없다.
- 내부 코드와 표시 코드: T-1-2는 화면에서 T-2, T-2-1은 화면에서 T-3이다.

## 2. 왜 바꿨나

교사 연수 운영을 위한 사용자 결정이다(2026-10-03). 연수 동안 모든 팀은 T-2 수업설계 방향 설정을 반드시 거치고, T-3 역할 배분은 팀이 생략할 수 있다.

T-3 역할 배분은 원래 보고서가 직접 읽는 절차라서 핵심으로 묶여 있었다. 생략할 수 있게 되면서 생략된 역할표를 읽는 경로를 함께 고쳤다(3절의 "유지할 것").

## 4. 되돌리는 절차

1. **운영 영향 확인 (읽기 전용).** 되돌리기 전에 T-3을 생략한 프로젝트 수를 센다.

   ```sql
   select count(distinct project_id) from project_procedure_skips where procedure_code = 'T-2-1';
   ```

   되돌린 뒤 이 프로젝트들은 T-3이 다시 핵심이 되지만 생략 상태는 그대로 남는다. 화면의 '건너뛰기 해제' 버튼과 해제 API(DELETE)는 핵심 절차에도 동작하므로, 해제 여부는 각 팀의 호스트가 정한다. 생략 기록을 일괄 삭제하지 않는다.

2. **origin/main 기준 새 워크트리에서 커밋을 되돌린다.**

   ```bash
   git log --oneline --no-merges --grep='연수 한정 핵심 절차'
   git revert <위에서 찾은 커밋>
   ```

   병합 커밋(PR 머지)이 아니라 위 명령으로 찾은 일반 커밋 하나만 되돌린다. 3절 "되돌릴 것" 표의 변경이 모두 이 커밋에 들어 있다.

3. **충돌 등으로 손으로 되돌릴 때**는 3절 "되돌릴 것" 표를 위에서부터 처리한다.
   - `shared/constants.js`: 상수를 원래 값으로 바꾸고 "⚠️ 교사 연수 한정 임시 설정" 주석 블록과 "(T-1-2는 하드코딩 참조가 없고 …)" 줄을 지운다. 목록 설명 줄은 `T-2-1(T-3 역할)`로 돌린다.
   - `procedureSkipGateway.test.js`: `toEqual` 기대값을 원래 값으로 바꾸고 "연수 한정" 주석과 it를 지운다.
   - 두 테스트 파일 끝의 `연수 한정 핵심 절차` describe를 지운다.
   - `CLAUDE.md`: "⚠️ 연수 한정 임시 변경" 줄을 지우고 코어 5 목록을 `T-1-1·T-2-1·A-1-2·A-2-1·A-2-2 — 보고서·AI가 하드코딩 참조`로 돌린다.
   - `docs/절차-문구-교체-인수인계.md`: 5절 끝의 "2026-10-03 교사 연수 한정 임시 변경" 메모를 지운다.
   - 이 문서를 지운다.

4. **남은 흔적 확인.** 아래 명령의 결과가 비어 있어야 한다. (유지할 코드의 주석 "연수 한정으로 T-3이 …"는 걸리지 않는다.)

   ```bash
   grep -rn "연수 한정 핵심 절차\|연수 한정 임시" shared server client/src CLAUDE.md docs --include='*.js' --include='*.jsx' --include='*.md'
   ```

## 5. 확인 방법

되돌린 뒤(그리고 이 설정을 처음 반영할 때도) 아래를 모두 통과시킨다.

```bash
node --input-type=module -e "import { UNSKIPPABLE_PROCEDURES, isProcedureSkippable } from './shared/constants.js'; console.log(UNSKIPPABLE_PROCEDURES, isProcedureSkippable('T-1-2'), isProcedureSkippable('T-2-1'))"
# 되돌린 뒤 기대값: ['T-1-1','T-2-1','A-1-2','A-2-1','A-2-2'] true false
# 연수 동안 기대값: ['T-1-1','T-1-2','A-1-2','A-2-1','A-2-2'] false true

cd server && npx vitest run --maxWorkers=2
cd client && npx vitest run
cd client && npx vite build
```

배포 뒤에는 호스트 계정으로 확인한다. 되돌린 뒤라면 T-3 역할 배분 화면에 '이 절차 건너뛰기' 버튼이 없고 T-2 수업설계 방향 설정 화면에는 있어야 한다. 연수 중 T-3을 생략한 프로젝트에서는 T-3 화면에 '건너뛰기 해제' 버튼이 보여야 한다.
