# 수업 아이디어 탐색 반영 QA

2026-10-03. 사용자 지시: 이미지 빼고 반영.

## 변경 범위

- 홈의 탐색 영역을 이미지·섬네일 없는 텍스트 중심 디자인으로 교체. 제목은 ‘수업 아이디어 탐색’.
- 3D 자유 탐색(`/graph?mode=explore`), 과목 중심 탐색(`/graph?mode=design&lens=pair`), 미래보기(`/futures-lab`)의 세 입구와 짧은 상황별 안내.
- 주제 검색은 보조 링크로 유지. AI 설계 예시 체험은 사용 안내에서 접근.
- 기존 프로젝트는 해당 프로젝트의 A-3로 안내. 가상의 프로젝트명이나 임의로 고른 프로젝트를 홈에 표시하지 않음.
- 앞서 준비한 탐색 대상·검토/복사/서버 보드 상태의 구분과 프로젝트 성취기준 저장 상태 표시 포함. 낙관적 칩을 저장 완료로 표시하지 않고, 재조회 실패/추가·제거 결과 미확인 시 다시 확인할 수 있음.
- 실제 서비스 로고와 기능 내부의 3D/키워드 그래프, 현재 미래보기 상세 디자인, API와 저장 형식 유지.
- 구버전 코드 삭제, 다과목 팀 선택, 탐색 간 새 공통 후보 전달, 자동 보드 채택/단계 이동, AI/DB 변경은 이번 범위에 없음.

## 로컬 검증

- 클라이언트 전체: 32개 파일 / 298개 테스트 통과.
- 서버 전체: 36개 파일 / 430개 테스트 통과. 첫 실행은 샌드박스의 HTTP listen EPERM으로 90개가 실패했고, 로컬 포트 허용 환경에서 같은 전체 검사를 재실행해 통과했다. 실패를 제외한 실행이 아니다.
- 프로덕션 빌드 통과. 기존의 큰 번들 경고는 남아 있음.
- 실제 React 컴포넌트와 서비스 CSS를 Vite에서 렌더링하여 세 링크의 이동 URL을 확인. 과목 입구가 기본 이웃 보기 대신 과목쌍 보기로 진입함.
- 1280 / 768 / 390 / 320px에서 가로 넘침 없음. 탐색 영역에 img/svg/canvas 없음. 브라우저 실행 오류 없음.
- 기존 회귀 검사에 미래보기→프로젝트, 읽기 전용, 단계 생략, 시뮬레이션 생성/계속, 보고서 관련 테스트가 포함됨. 이는 모의 AI·DB 기반 자동 검사이며 실제 운영 AI로 새 프로젝트와 보고서를 생성한 검증은 아니다.

## 동시 작업과 복구

기준 main은 `ab20e3b`(PR #147 포함). Claude의 PR #148은 별도로 유지하며, AI·절차 생략/역할 관련 수정은 이 PR에서 변경하지 않는다. 운영 직전 최신 main 및 병합 충돌 여부를 다시 확인한다.

배포는 PR 전체 검사 성공 뒤 진행한다. 문제가 생기면 이번 UI/상태 안내의 배포 커밋만 revert하고 동일 검사를 거쳐 재배포한다. main 강제 이동, DB 롤백, 공유 캐시 삭제는 하지 않는다. 기존 롤백 태그는 보존한다.

CI·배포 결과와 실제 운영 응답은 PR/배포 실행 기록으로 확인한다. 로그와 단순 HTTP 성공만으로 로그인 후 전체 사용 흐름까지 검증됐다고 표현하지 않는다.
